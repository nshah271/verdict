known noise in this dataset

verdict is honest about its own false positives. the corpus you're looking at contains real findings produced by today's checks running on older commits. some of them are noise we already know about:

  • hallucinated_api can fire on MagicMock receivers and certain pathlib / ast inferences in commits before PR #20. (jedi resolves Path as PurePath, which lacks write_text / read_text.)
  • coverage_delta over-counts comment-only diff lines, inflating its denominator.
  • vacuous_tests heuristic D over-fires on legitimate helper tests that happen not to call any newly-added function.
  • tests/fixtures/* files are intentionally-bad code written so a check has something to detect. verdict flagging them is correct, just embarrassing-looking. use the fixture filter above to exclude.

these are not pre-filtered from the charts. use the toggles above to slice the corpus the way you want to read it.
