Seven checks

Each one targets a distinct class of agent failure.

Five static checks run on the AST. Two dynamic checks run the test suite under a tracer. All seven are auto-discovered — adding an eighth is one file.

dead_function

STATIC

A function was added but is never referenced anywhere. Classic “wrote a helper to look productive, forgot to wire it up.”

vacuous_tests

STATIC

Test functions that don’t actually verify anything. Empty body, no asserts, mock-only assertions, or never reach new code.

hallucinated_api

STATIC

Calls to methods that don’t exist on the inferred type. list.add(), str.uppercase(), dict.put(). Powered by Jedi.

phantom_files

STATIC

Agent transcript claims a file was created, but the file isn’t on disk. Catches hallucinated file creation.

suppressed_exception

STATIC

Bare except:, except Exception: pass, log-and-continue. The “make the error go away” anti-fix.

trace

DYNAMIC

Runs pytest under sys.settrace. Any newly-added function whose body never actually executes gets flagged.

coverage_delta

DYNAMIC

Line-level coverage on just the diff’s added lines. Below 50%? Flagged. Sharper than whole-file coverage.

Five surfaces, one binary

Use it where you already are.

Same scorecard powers a CLI, an MCP tool, a Bob mode, an editor tab, a CI bot, and an analytics dashboard. Pick whichever fits the moment.

01 · CLI

verdict run

One-shot audit on any git repo. Prints a scorecard, writes verdict-report.json.

02 · MCP

verdict-mcp

Bob (or any MCP client) calls check_diff mid-conversation. Live tool-use.

03 · Bob mode

/verify + Verifier

Custom Mode + slash command. Read-only auditor agent that narrates findings.

04 · Editor

Verdict tab

Bottom-panel webview in Bob / VS Code. Filterable findings list with “Fix with Bob” handoff.

05 · CI

GitHub Action

PR comment with deep links to every finding. Green check by default, opt into fail-on for strictness.

Five-minute install

On a fresh machine, end to end.

01

Install the CLI

pip install myverdict
verdict --help
02

Hook into Bob (machine-wide)

verdict mcp-install --global
verdict bob-mode-install --global
# restart Bob
Drop --global for per-project install under .bob/.
03

Install the editor tab

Download verdict-vscode-0.2.0.vsix, drop it into any project folder, right-click in the editor → Install Extension VSIX, reload the window.
04

Try it on a real repo

cd <some-git-repo>
verdict run --diff-range HEAD~1
05

Add to CI

# .github/workflows/verdict.yml
on: pull_request
permissions: { contents: read, pull-requests: write }
jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: nshah271/verdict@main
